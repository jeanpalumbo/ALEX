## 2. Cómo se elige el fragmento

Orquestador: `/workspace/growth/bin/auto_batch.sh` → `auto_batch.py` (nice 19, 2 hilos, `flock /tmp/auto_batch.lock`). **Nunca publica ni llama a Buffer**.

1. **Candidatos** sin LLM: clips/moments frescos (Twitch top clips + clustering ±90 s; Kick chat spikes en VODs ~72 h).
2. **Filtro duro**: edad (`--max-age`, ES típ. 12–72 h; filler EN 24 h); saturación YT; no duplicar vod+offset±90 s vs `queue_es.json` / campaign log; blacklist títulos sensibles; rotación máx. 1 streamer/tanda.
3. Descarga solo el tramo (offset−40…+30 s) + chat del mismo tramo.
4. Shortlist → **una** llamada `cc-lean --model haiku` por tanda: `keep`, `sensitive`, hook, title, hashtags, caption_fixes. `keep=false` o `sensitive=true` → descarte.
5. QA ffmpeg/ffprobe: 1080×1920, duración (clásico ~22–32 s / v2 ~14–22 s), black/freeze, cara YuNet 0–1,5 s (soft en IRL), loudnorm −14±1,5 LUFS, `title_lint`.

Heurística clásica del pipeline (`PIPELINE.md`): z-score volumen, palabras/s, gancho en 1ª frase, cortes de escena; score 0–100 + LLM.

## 3. Edición

| Pieza | Qué se hace (producción actual) |
|---|---|
| **Corte** | Ventana ~20–55 s (clásico) / más corta en v2; empieza/termina en frase cuando se puede |
| **Encuadre** | 9:16 1080×1920; cara YuNet + paneo; gaming facecam pequeña → blur+crop (flag QA) |
| **Subtítulos** | Whisper (`small` en batch); ASS quemado 2–3 palabras/bloque; SRT aparte. EN→ES: Argos segmento + corrección manual a veces (slang) |
| **Chat overlay** | TwitchDownloader JSON en layouts stacked/full (v2); Kick: overlay vacío |
| **Gancho** | Texto overlay ≤7 palabras (haiku); emoji en título |
| **Audio** | loudnorm ≈ −14 LUFS, true peak −1,5 dBTP (`loudnorm.py`) |
| **Voz / música extra** | **No** se añade TTS ni banda sonora propia. Audio = stream original. Evitar tramos con música comercial (riesgo Content ID — `ELECCION_ES.md`) |
| **Crédito** | Descripción: «Todo el crédito a \<streamer\>: síguele en … twitch.tv / kick.com» |
| **Host media** | MP4 subido a release `jeanpalumbo/clipendo-media`; Buffer apunta a esa URL (HTTP 200 verificado) |

Render: H.264 High CRF 21, AAC 128k 48 kHz, +faststart.

## 4. Títulos y hashtags

Salida haiku (plan `auto_batch_plan.md`):
- **Título:** 3–8 palabras, ≤45 caracteres, **1 palabra en MAYÚSCULAS**, emoji final; a menudo `| Streamer` en variantes antiguas.
- **Hashtags:** típ. 3 — `#shorts` + streamer + tema (`#knekro #wow`, `#spreen #dedsafio`, …). Lint: hoy se cambió `#scam`→`#react` en Jynxzi (`ESTADO_2026-11-06_1200.md`).
